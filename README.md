# Movie Explorer

A responsive React application for discovering TV shows through the public TVMaze API.

## Features

- Landing page with navigation and call-to-action
- Responsive show grid populated from TVMaze
- Debounced title search
- Detail modal with summary, rating, genres, dates, and external show page
- Loading, empty, and network-error states
- Keyboard-accessible modal (Escape closes it)

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```
